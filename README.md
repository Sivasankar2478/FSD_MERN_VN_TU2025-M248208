## 📚 **Project 1 – Book Store Application (MERN)**

A complete MERN full-stack Book Selling application.

### 🔧 Tech Stack
- **Frontend:** React.js, Axios, React Router  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT  
- **Features:**
  - User registration & login  
  - Admin & Seller features  
  - Add / update / delete books  
  - Browse & order books  
  - Order management dashboard  

Each module is documented inside the **documentation/** folder.

---

## 🏥 **Project 2 – DocSpot (Doctor Appointment System)**

A MERN full-stack hospital appointment management app.

### 🔧 Tech Stack
- **Frontend:** React.js, Redux Toolkit  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Features:**
  - Patient login & registration  
  - Doctor dashboards  
  - Appointment booking system     
  - Admin monitoring panel  

Documentation is included inside **documentation/** folder.
