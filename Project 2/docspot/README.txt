DocSpot 3 - Full Stack Doctor Booking System
--------------------------------------------

This project is a complete full-stack doctor appointment system:

- Backend: Node.js, Express, MongoDB, JWT, Multer
- Frontend: React (Vite), Bootstrap, Material UI, Dark Mode

To run:

1) Backend
   cd server
   npm install
   npm run dev

2) Frontend
   cd client
   npm install
   npm run dev

Mongo URI is preconfigured to: mongodb://localhost:27017/docspot3
